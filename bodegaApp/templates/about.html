Proyecto

Gestión de bodegas y vinos

Este proyecto fue desarrollado como una aplicación web para organizar y administrar bodegas vitivinícolas de manera sencilla, moderna y práctica. La idea principal es centralizar la información de cada bodega y de los vinos que ofrece, facilitando la gestión de un catálogo completo para clientes, administradores o personas interesadas en el mundo del vino.

La aplicación permite registrar bodegas con sus datos principales, como nombre, dirección, descripción, teléfono, email, ubicación y sitio web. Además, cada bodega puede tener varios vinos asociados, con información detallada como tipo, varietal, precio y descripción.

En conjunto, la plataforma funciona como un pequeño sistema de administración para una bodega, donde se pueden crear, consultar, editar y eliminar registros de manera intuitiva. Esto hace que sea útil tanto para exhibir productos como para gestionar el inventario y la información comercial de una empresa vitivinícola.

Gestión de bodegas

Registro y administración de cada establecimiento, con datos completos y una imagen representativa.

Catálogo de vinos

Organización por tipo, varietal, descripción y precio para ofrecer una experiencia clara y ordenada.

Tecnología

Construido con Django, SQLite y una interfaz moderna con Tailwind CSS para una experiencia visual simple y elegante.
